## ❓ QUESTIONS FRÉQUENTES & RÉPONSES

### Q1 : "Et si le téléphone est volé ?"
**R :** "Excellente question ! En production, on ajoute :
- Verrouillage biométrique (empreinte digitale)
- Chiffrement des données locales
- Effacement à distance possible"

### Q2 : "Le réseau est très mauvais dans certaines zones."
**R :** "Justement ! C'est pour ça que l'app fonctionne 100% hors-ligne. L'agent peut rester 1 semaine sans Internet, faire 50 enquêtes, et tout se synchronise automatiquement dès qu'il a du réseau."

### Q3 : "Combien coûte cette solution ?"
**R :** "On peut commencer avec un pilote dans 1 CPS. Budget minimal :
- Smartphones : ~100€/agent (ou smartphones existants)
- Hébergement cloud : ~50€/mois pour tout le pays
- Formation : 1 demi-journée par CPS
Total : Rentabilisé en 2 mois grâce aux économies papier + productivité."

### Q4 : "Les agents vont-ils accepter le changement ?"
**R :** "C'est LA question critique. Notre stratégie :
- Interface plus simple que le papier
- Démo terrain avec les agents
- Formation hands-on
- Pilote dans 1 CPS volontaire d'abord
- Les agents verront qu'ils gagnent du temps, ils adopteront naturellement."

### Q5 : "Quelle est la prochaine étape ?"
**R :** "Proposition :
1. **Maintenant → +2 semaines** : Peaufinage du MVP
2. **+1 mois** : Pilote dans 1 CPS (ex: Abomey-Calavi)
3. **+3 mois** : Évaluation et ajustements
4. **+6 mois** : Déploiement dans 3-5 CPS supplémentaires
5. **+12 mois** : Déploiement national"
